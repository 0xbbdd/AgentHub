# v1.66.1 更新说明

## 修复

- **计费「归并」报「归并目标不能是模型自身」修复**（issue #98）：「未配置价格的模型」里，模型自己的价格已配置、只是生效日期晚于历史记录时（典型场景：刚拉取过价格），点「归并」会把模型自己排进候选并默认选中，确认后必然报错——现在候选列表已排除自身；这类模型会直接标注「已有价格（… 起）、未覆盖历史记录」，并提供一键「补生效日期」：把价格段生效起点补到最早记录日，历史费用立即按现价重算（归并只保留给渠道变体模型名场景），未配置列表行内也可直接操作
- **补录历史价沿用原来源**：对远程价补录生效日期后仍标记为「远程」，后续远程价格源更新继续生效，不会因补录变成手动价而冻结
- **号池账号副行收口**：UID 改为固定「UID」小按钮（点击弹窗看全文）；副行限宽锚定名称行，备注过长在剩余空间内收缩省略号，不再撑宽账号列

# v1.66.0 更新说明

## 新功能

- **调度策略弹窗**：号池列表上方的「渠道账号调度策略」与「成本档位」两个下拉收进「调度策略」小弹窗（工具栏「添加账号」左侧新增入口按钮），改动即时生效
- **多选 / 全选 + 批量操作**：账号列表新增行选与全选；选中后工具栏出现「导出」（导出账号元数据 JSON，不含凭据）与「批量删除」（二次确认，删除随 WebDAV 同步传播到其他设备）
- **账号备注**：操作列新增「备注」按钮，弹窗输入即可添加 / 编辑（留空保存即清除）；备注落库后随 WebDAV 号池同步传播（合并时备注新者胜），账号副行同步展示备注（过长省略号，点击可编辑）
- **账号列信息优化**：副行依次展示导入方式、UID（点击弹窗看全文）、备注；与「本机登录」徽标同行排列

## 修复

- **文案统一**：账号操作「移出」改为「删除」（确认弹窗同步），「切到 IDE」改为「切换」
