# v1.72.0 更新说明

反代网关的「用量统计」页面整体重做（对应 issue #138）。核心变化是：**一个时间区间统摄全页**——顶部选定区间后，指标卡、趋势、排行、各 Key 用量、请求明细全部同步切换，口径一致，不再出现「指标卡说今日、图表说近 7 日」的矛盾。

## 新增

- **顶部时间筛选**：今天 / 近 7 天 / 近 30 天 / 近 90 天 / 自定义区间。切换后全页同步；区间跨度 ≤ 2 天自动按小时聚合，其余按天，筛选栏固定在页面顶部
- **请求趋势图重做**：改用折线图，支持请求数 / Token / 成功率 / 延迟四种指标切换；鼠标悬停显示该点的请求数、成功与失败数、输入/输出 Token、成功率、TTFT 与总耗时；数据点较少时直接在点上标注数值
- **Token 构成 / 请求状态两张环形图**：输入与输出 Token 占比、缓存命中率；成功 2xx / 客户端 4xx / 服务端 5xx / 无响应分布
- **用量占比 TOP 增强**：新增「请求 Tok」「响应 Tok」两列，并补上成功率与平均 TTFT；维度可在渠道 / 模型 / Key / 账号之间切换，排序可按请求数或 Token
- **各 Key 用量专表**：按总 Token 倒序列出每把 Key 的请求数、输入/输出 Token、成功率、平均 TTFT、最近使用时间；行内「筛选」按钮一键下钻到明细
- **请求明细筛选增强**：新增 Key 名 / Key ID 模糊搜索、模型模糊搜索、渠道与状态筛选，并显示当前筛选命中的条数与 Token 汇总

## 改进

- 指标卡改为区间口径（总请求 / 总 Token / 成功率 / 平均 TTFT / 输入 Token / 输出 Token），与下方所有模块统一；成功率低于 99% 标红
- 趋势图、排行表、Key 表、明细表全部随请求流水实时刷新

## 说明

- 本版只改统计与展示层，**网关的转发、路由、记账逻辑一行未动**；数据库表结构也未变（新统计全部由现有流水表实时聚合）
- 「总 Token」= 输入 + 输出；缓存读 / 缓存写属于输入的子集，单独以「缓存命中率」呈现，不计入总量，避免重复计数
