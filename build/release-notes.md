# v1.64.2 更新说明

## 修复

- **登录会话守卫补齐**：Qoder 设备授权登录轮询补会话一致性守卫（对齐 Cline 同款）——轮询请求在途时取消并另发登录，旧轮询结果不再终结新登录会话（此前并发两次登录时，新登录可能被旧结果静默终结、提示错乱）
- **JSON 导入账号崩溃修复**：粘贴 / 文件导入无 uid 的账号记录时不再崩溃（Node 22 环境缺 crypto 引入的启动期隐患）
- **错误分类口径统一**：流中错误与异常路径同口径——确定性拒绝（参数错误 / 提示过长 / 模型无权限）在流中路径同样终止不再逐个换号，客户端参数错误不再把整个号池逐个冷却；HTTP 400 参数类不再冷却账号（换任何号都同错，冷却无意义）
- **WorkBuddy / 渠道白名单误罚修复**：流内 6004（模型级限流）与 11128（渠道白名单拦截）补 code 字段判定——上游错误文案不含数字码时不再漏判，6004 恢复「账号×模型冷却 + 对齐墙钟」的正确处置，11128 恢复渠道级拦截（不再把好号计入熔断）
- **AutoClaw 凭据缓存修复**：401 自动刷新后，刷新得到的凭证不再被误判为「登录态已更换」而丢弃——后续请求不再拿库内旧令牌反复 401、反复用已被轮换的旧 refresh_token 刷新（此前会导致账号被误判需重登、并与桌面端抢占同一凭据）
- **AutoClaw 身份句改写修复**：出站改写改逐字符 ASCII 折叠（对齐参照实现），含 Unicode 扩展字符的 system 提示词不再因大小写折叠错位而被切坏；模型目录拉取补登录态失效码判定（不再把失效误报成「目录结构可能已变更」）
- **Qoder 凭据与排队修复**：设备令牌到期时间改双形态解析（上游回毫秒数字时不再解析失败落 0、临期自动续期恢复生效）；免费模型排队中（10605）按限流退避处理，不再落入「上游不稳定」的熔断节奏；签名会话池并发创建不再产生孤儿实例；签名器一次性失败（装完客户端 / 临时 IO 错）后无需重启即可恢复；签到补 409「已领过」成功语义与活动列表实时刷新；国际版签到接口兜底对齐官方域名（不再跨区打国内域）；developer 角色消息归并 system 且全部前置（系统提示词不再静默丢失）
- **号池跨机同步加固**：采纳远端凭据改为合并式元数据（本机设备指纹 / 切号快照不再被空的远端元数据抹掉，跨机同步后 Qoder 签名、小浣熊指纹、ZCode 切号不再失效）；自愈以远端凭据有效为前提（两端都过期的死号不再被「自愈」成在线进调度）
- **ZCode 思考参数修复**：Anthropic 通道开思考时不再同时发送 temperature / top_p（上游会拒绝两者并存）；「关闭思考」折叠为最低档（GLM 对显式关闭必返回 400）；沙箱验证窗内联脚本转义加固
- **ModelScope 续期链修复**：OAuth 客户端密钥落库前加密（此前重复执行 OAuth 登录时密钥被静默剥离，续期链断裂提示「缺少 OAuth 客户端信息」）
- **LobsterAI 晚到回调修复**：宽限期内到达的登录回调只落库不再经当前会话回传（此前可能把成功结果串给另一渠道进行中的登录）
- **CatPaw 会话清理挂点**：账号删除 / 停用时同步作废其名下会话（工具续接窗口内不再把结果提交到已消失账号）；登录态导入的账号身份口径与桌面端实时登录态对齐
- **WorkBuddy 工具声明修复**：字符串形态的 tool_choice:"none" 同样撤除工具声明（与 Trae 渠道同口径，上游语义要求连声明一起撤）
- **Cline 小修**：max_tokens 为 0 / 负数按缺失处理（不再原样透传被上游拒绝）；余额查询补空值守卫
- **日志脱敏补齐**：client_secret / clientSecret / device_token / machineToken 等带前缀键名形态纳入脱敏（错误体回显这些凭据不再原样落日志与导出）；操作日志 target 字段统一过脱敏；小浣熊写盘临时文件带进程号（双方同时刷新不互踩）
- **禁用模型口径统一**：请求入口的禁用判定与 /v1/models 出口同为大小写不敏感（变体大小写不再绕过入口直通上游）
- **杂项**：模型归属解析补渠道开关过滤（不再把请求强制打进已关闭渠道）；上游并发上限配置下限钳制（误配 0 不再锁死网关）；用量流水补行数上限；Trae 本机导入扫描防文件竞态（官方客户端正在写登录态时不再整页失败）；Trae 登录空身份拒绝落库（不再产生重复账号）

# v1.64.1 更新说明

## 修复

- **Cline 登录加固**：设备授权轮询补会话一致性守卫——轮询请求在途时取消并另发登录，旧轮询结果不再终结新登录会话（此前新会话可能被旧结果连同步 timer 一起终结、提示错乱）
- **Cline 限流冷却对齐**：429 错误在文案没有「Try again in」等待时长时，改接上游 Retry-After 响应头对齐冷却（此前会先白打一次 1 秒重试、再落短冷却，墙钟对齐失效）
- **Cline 请求头配置语义统一**：模型目录与余额查询的请求头收敛到与对话 / 登录 / 续期同一实现——headers.json 里对伪装头（如 X-CLIENT-TYPE）的覆盖 / 删空此前对这两处不生效
- **Cline 模型目录元数据稳定**：同步官方目录后，模型的思考开关与上下文长度改为继承本地目录既有值（查不到的新模型按家族推断），不再与静态兜底跳变（此前同步后 solar-pro4 的思考开关会被误标为支持、全部上下文长度归 0）
