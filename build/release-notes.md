# v1.63.0 更新说明

## 新功能

- **WebDAV 同步设置页改造**：「测试连接 / 保存设置 / 清除配置」三个按钮改为横向排列（此前被窄栏挤成竖排）；原「号池同步」卡升级为「快捷同步」——用量 / 技能 / 号池 / 记忆四大板块逐一手动触发，各带一句话说明、实时状态与上次同步时间，未配置统一服务器时统一给出「去配置」入口

## 修复

- **AutoClaw 登录三处加固**：国际版「粘贴回调地址」不再假成功（此前提示成功但实际未登录、会话悬挂到 3 分钟超时）；回环回调在初始化完成前的窗口期收到请求（手动刷新旧回调页、上轮残留页预取）不再有崩主进程的隐患；窗口期内取消 / 重复发起登录不再泄漏回环 server
- **号池定时同步不再静默跳过**：同步任务启动瞬间抛错（手动同步进行中 / 同步锁被占）时也回滚计时记账，当天 daily 档失败后下一轮自动补跑（此前当天档期直接丢失）
- **设置页停用板块不再静默改写用户设置**：停用「反代网关」不再把「记住网关开关」强写为关（此前重新启用模块后网关不再自启、且无从得知设置被改），模块开关只做运行时启停；停用「用量统计」时同步取消在途同步，不再把刚关掉的数据库惰性重开
- **配置加载改为深合并**：以默认值为基线补全任意层级的缺失字段，旧版后端 / 字段重命名 / mock 未同步时不再整页白屏（预防性加固，当前版本不可触发）
- **S3 兼容存储文件名修复**：对象列表的 href 按百分号编码，与 WebDAV 侧契约对齐——含空格 / 中文 / & 的文件名此前会得到非法 URL
- 同步锁加固：号池同步的占锁与收尾收进同一保护块，消除极端情况下同步锁永久泄漏、四个模块同步入口被拒需重启恢复的隐患

## 说明

- 「墓碑」内部重构（纯优化，行为与结果不变）：Key 同步的墓碑生效循环改 Key 快照，消除随 Key 数量放大的重复聚合查询（O(n²)）；墓碑写入统一收口；远端无墓碑时不再上传空对象
- 测试脚本沙箱化：failover T10 断言恢复确定性（该偶发红在基线即存在）；checkin-auto 自测默认使用临时沙箱，不再读写真实数据目录
- README 渠道表补齐 ModelScope（魔搭）/ CatPaw（美团）/ AutoClaw 双区等新增渠道

# v1.62.0 更新说明

## 新功能

- **API Keys 与模型映射跨设备同步补全（#92）**：API Key 的改名 / 改配额 / 启停 / 删除现在会传播到其他设备（updated_at LWW 仲裁 + 删除墓碑，此前只补新增）；**号池同步新增定时**（设置 · 同步时间 · 反代网关：每小时档 1/2/3/6/12 小时或每天固定时刻，此前只能手动）；**首次配置统一服务器自动跑一次号池同步**——换台电脑配好服务器，API Keys 与全渠道反向模型映射开箱即得；同步结果明细展示「补 / 更新 / 删 Key N」
- **统一服务器支持 S3 兼容对象存储（#89）**：设置 · 数据存储可切换 WebDAV / S3 兼容存储（阿里云 OSS、腾讯云 COS、Cloudflare R2、MinIO、群晖等），SigV4 手写签名零 npm 依赖；技能 / 用量 / 号池 / 记忆四个同步引擎与「配置齐全」判断零改动无缝切换；号池压缩包加密口令支持独立设置（缺省沿用密码 / SecretKey，与历史行为兼容）
- **四大板块启用开关（#91 轻量模式）**：设置 · 通用 · 模块顺序的每一项可启停——停用后左上角置灰不可点，该板块后台的定时器 / 目录监听 / 网关服务 / 数据库全部停止、托盘入口同步隐藏；记忆中枢停用可释放约 80~130MB（全应用内存大头），用量停用不再打开本地库；「至少保留一个板块」防呆，停用反代 / 记忆前弹提示说明影响（网关客户端断开 / 已注入 Agent 的记忆 MCP 不可用）

## 修复

- **WebDAV 服务器配置丢失（#95）**：设置页任何整份保存（切主题、拖模块排序、改反代设置）不再用旧快照冲掉统一服务器配置；系统密钥解密失败（换机 / DPAPI 变化）不再把密文覆盖成空（地址账号还在密码没了的根因）；迁移自愈不再让旧服务器凭据「复活」；设置页新增「清除配置」显式入口（唯一能清掉已存密码的通道）
- **用量归并「确认归并没有任何反应」（#96）**：归并记录放开供应商精确价限制——目标只有其它供应商精确价时按估算计费，不再永远滞留未配置列表（保持「精确 > 通配 > 错配兜底」层级，无别名记录的既有计费口径不变）；归并成功 / 无价可套 / 失败都有明确提示（全局 toast + 弹窗内红字，此前失败提示被弹窗遮罩挡住）；归并目标下拉附价格来源与「仅供应商精确价」徽标；旧版本设备上传价格表不再抹掉本机归并映射；顺带修复旧版 DosageSync 目录迁移后首次打开即崩（no such column: credits）的问题
- **/v1/models 与错误码（#90）**：渠道被「上游启闭」关闭、或一个账号都没有（没有号池）时不再返回该渠道模型；有账号但暂时耗尽 / 冷却仍列出（避免客户端模型列表整体闪没），请求时拿到 503/402 明确文案；访问「目录里查得到但当前不可用」的模型返回 400 channel_disabled（报渠道名与指引，与「模型不存在」的 model_not_found 区分）；fixed 策略下指定渠道被关闭不再「透传试错」；静默回退模型时附 x-agenthub-fallback 响应头（流式为 SSE 注释帧）
- 「保存并重启服务后上游启闭被重置」的修复（2a8b6a5，v1.60.0 之后合入 main）随本版正式发出

## 说明

- **跨模块同步互斥**：全应用同一时刻只放行一个远端同步任务，定时与手动并发时自动跳过本轮（定时下轮补跑、手动提示原因）
- 号池定时同步失败会回滚记账，当天 / 下轮自动补跑；改周期即时生效无需重启
- 板块开关键名与前端 ModuleKey 对齐（用量板块 = sync）；开关为唯一写入口（module_toggle IPC），设置页整份保存对其磁盘优先，不会被旧快照写回
- 升级注意：旧版「记忆中枢已关闭」状态自动迁移进新开关；号池加密口令未显式设置时与历史包完全兼容，无需任何迁移
- 新增 6 个自测脚本：用量归并（16 断言）、WebDAV 配置持久（19）、板块开关（12）、Key LWW 与墓碑（17）、models 过滤（16，真实 HTTP 假上游）、S3 传输（14，自建独立重算 SigV4 的假 S3 服务做全链路回环）
