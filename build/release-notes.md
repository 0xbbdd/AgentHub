# v1.61.0 更新说明

## 新功能

- 新增 **AutoClaw** 双渠道反代接入：`AutoClaw 国内版`（智谱 AutoGLM 加速站）与 `AutoClaw 国际版`（国际站），两地同套协议与签名指纹、账号体系互相独立，各自独立启停 / 路由 / 号池
- **对话转发**：标准 OpenAI 兼容流式，支持工具调用与图片输入；模型路由自动区分计费通道（Coding Plan / 会员按量 / 服务端自动选型），响应回写客户端请求的模型名；远程模型目录一键拉取（未拉取时按两地实测的静态兜底清单 GLM-5.3 / GLM-5.3-Flash 开箱）
- **上游闸门自动处理**：system 提示词白名单规范化（自动前置官方客户端身份段、外来身份句整名改写、幂等不重复）；`max_tokens` 小值自动归一到 10000（上游对小正整数一律拒收且无错误体，撞上时错误提示里附实测排查方向）
- **国内版登录**：添加账号新增「手机验证码」页签——输手机号 → 官方短信通道发码 → 验证入池，全程走官方接口
- **国际版登录**：OAuth 网页登录——点「打开登录页」先弹出官方风控滑块（阿里云验证，前端原样移植官方客户端的求解流程），验证通过自动打开 Z.ai 登录页，回调落在官方登记的四个本机回环端口之一自动入池；支持 Z.ai 账号（Google 通道协议已就绪）
- **从本机客户端导入**：自动识别 `%APPDATA%/AutoClaw/auth.json` 登录态（safeStorage 加密自动解密）与 `~/.openclaw-autoclaw/openclaw.json` 网关配置；国内/国际两区共用同一登录态文件且无地区标记，故两区各给出导入入口、由您选择归属（选错会 401，换一项重导即可）
- **每日签到**：两区每日 `daily_signin` 领积分，判据看积分到账而非 HTTP 状态（已领过如实标「今天已签到」），失败自动拉任务列表归因；支持按渠道的自动签到
- **余额**：积分钱包 + 订阅信息聚合展示（钱包明细按优先级排序，即将过期积分提示）

## 说明

- **token 刷新只读不回写**：AutoClaw 服务端轮换 refresh_token，网关刷新结果只进进程内凭证缓存、不落库——避免与桌面端自己的刷新互相顶掉导致掉登录；代价是网关重启后可能需要重新导入一次登录态
- 客户端版本号、签名密钥、全部端点路径在「规则文件 → headers.json」的 autoclaw / autoclaw_intl 段，客户端升级后改配置即热生效，无需等待发版
- LLM 对话域与账号域的版本号不同（1.17.8 / 1.18.5），后者是模型目录的版本门控，两者都已在配置里
- 新增 `tools/proxy-autoclaw-selftest.cjs` 自测：签名向量、两域请求头互斥（LLM 域禁发 X-Harness-Type / userapi 域必发）、system 规范化幂等、max_tokens 归一、模型路由、假上游端到端（对话 / 目录 / 余额 / 签到幂等 / 刷新不落库 / 凭证缓存）与登录链路
- AutoClaw 双区尚未与真实上游联调（本机无登录态），协议与判据均按官方客户端逆向实证移植；首次真实使用若遇异常欢迎反馈
