# v1.68.0 更新说明

## 新功能

- **积分日历（号池新增页）**：把各渠道按包发放的积分 / Token 套餐逐包列出，按到期时间升序，一眼看清「哪笔钱哪天到期、还剩多少」。三档视图可切：表格（逐笔明细，默认）、时间轴（哪几天集中掉）、见底曲线（哪天腰斩、什么时候归零）；已过期满 2 天的陈年包自动收进「历史过期积分」按钮，一行不丢；上游不拆包的渠道按账号出一条汇总行，全部有额度概念的渠道都有得看
- **号池账号行可展开逐包明细**：账号名前新增展开按钮，点开是该号每个包的已用 / 总额 / 剩余 / 到期 / 状态与已用进度条，零新增请求（数据随号池视图下发）；「上游不给面值」的包显示「—」而不是「不限」，与日历同口径
- **五渠道接入逐包明细**：Trae / WorkBuddy 双区 / zcode / LobsterAI / Qoder 双区刷新额度时按包落库，是日历与号池展开的数据源。随之有两个如实的行为变化：已过期但还有剩余的包不再计入账号余额、剩余为 0 的包不再把账号标成「明天到期」
- **「即将到期」预警阈值可配**（设置 · 反代网关 · 额度监控）：原来固定 1 天，现在 0~3650 天可调（0 = 关闭预警），号池到期徽标与逐包明细共用同一个值，改设置即时生效
- **逐包明细随号池 WebDAV 快照同步**：多设备之间日历一致；与旧版本互通安全（旧快照没有该字段时本机包集原样保留，不会清空）
- **Trae 不限量包不再整条丢掉**：credits_limit < 0 的「不限量」包此前被整条丢弃（日历少一行、连带丢到期），现在如实按「不限」出包，账号余额折成「不限」哨兵——选号豁免余额判定、不参与扣减，被误标耗尽的也能随额度刷新复活
- **AutoClaw 本机导入适配新版客户端**：登录态已迁移到按地区分的多账号目录（AutoClaw-official / AutoClaw-oversea-official），导入器按目录名精确归属地区、不再两区各猜一条；旧版 auth.json / openclaw.json 继续兼容；单个地区解密失败不再把另一区一起标成「加密不可读」

## 修复

- **额度刷新的到期时间不再回填旧值**：包集派生出「长期 / 无在用到期」时，此前会把库里旧的账号级到期时间回填回去——混合包场景（有限包已过期 + 不限量包在库）下，不限量账号会被「余额已到期」反复标死再复活打乒乓；现在派生成功就整体信派生值
- **Trae 三条包过滤**：隐藏包 / 已取消 / 兑换码包不再计入余额（部分账号余额会变小，属如实修正）；到期归一与其它渠道同口径，不再出现「还剩几万年」的包
- **侧栏「渠道额度」卡片不再列出死渠道**：已过期且在线余额合计为 0 的渠道不再占行（此前可用与不可用长得一模一样，渠道一多把要看的挤到折叠线下）；空态文案区分「无可用余额渠道（已过期或额度耗尽）」与「号池尚未接入或加载中」

# v1.67.0 更新说明

## 新功能

- **单请求最多尝试渠道数上限 5 → 10**（issue #104）：配置页该项原来超过 5 会被静默按 5 保存（改大保存后重开仍是 5，容易被误判为「配置不生效」）；现在范围 1~10、超出按 10 保存，页面已明示规则。同步放大每模型上游尝试预算（随上限提升为「上限 + 1」、最低 6 次）——调到 10 时上游失败可真正继续尝试更多渠道，不再被旧预算提前截断
