# v1.66.0 更新说明

## 新功能

- **调度策略弹窗**：号池列表上方的「渠道账号调度策略」与「成本档位」两个下拉收进「调度策略」小弹窗（工具栏「添加账号」左侧新增入口按钮），改动即时生效
- **多选 / 全选 + 批量操作**：账号列表新增行选与全选；选中后工具栏出现「导出」（导出账号元数据 JSON，不含凭据）与「批量删除」（二次确认，删除随 WebDAV 同步传播到其他设备）
- **账号备注**：操作列新增「备注」按钮，弹窗输入即可添加 / 编辑（留空保存即清除）；备注落库后随 WebDAV 号池同步传播（合并时备注新者胜），账号副行同步展示备注（过长省略号，点击可编辑）
- **账号列信息优化**：副行依次展示导入方式、UID（点击弹窗看全文）、备注；与「本机登录」徽标同行排列

## 修复

- **文案统一**：账号操作「移出」改为「删除」（确认弹窗同步），「切到 IDE」改为「切换」

# v1.65.0 更新说明

## 改进

- **上游启闭弹窗改版**：弹窗加宽（440→580），渠道列表改为两列卡片布局（图标 + 名称 + 状态 + 开关），防长渠道名撑破列宽；列表末尾新增「更多渠道等待添加」占位卡；开关不再显示悬浮提示文案（点击切换逻辑不变）
- **侧栏入口绿描边**：左上角「上游启闭」小按钮改为绿色描边常态，悬停点亮加深

## 修复

- **Cline 免费池误锁死修复**：余额 0 的账号不再被误标 exhausted 冷却到次日——Cline 上游允许余额记负（欠费小额仍可用），真实门禁是每日额度的 429 限流；此前免费池账号余额恒 0 时被永久锁在调度外且每日额度从未真正耗尽
- **Cline 登录并发修复**：设备授权在途期间另发的登录不再被旧流程覆盖——startDeviceAuth 网络等待返回后补会话占位守卫，新登录会话不再 timer 孤儿化、不再卡死「登录中」
