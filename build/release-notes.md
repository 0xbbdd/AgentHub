# v1.62.0 更新说明

## 新功能

- **API Keys 与模型映射跨设备同步补全（#92）**：API Key 的改名 / 改配额 / 启停 / 删除现在会传播到其他设备（updated_at LWW 仲裁 + 删除墓碑，此前只补新增）；**号池同步新增定时**（设置 · 同步时间 · 反代网关：每小时档 1/2/3/6/12 小时或每天固定时刻，此前只能手动）；**首次配置统一服务器自动跑一次号池同步**——换台电脑配好服务器，API Keys 与全渠道反向模型映射开箱即得；同步结果明细展示「补 / 更新 / 删 Key N」
- **统一服务器支持 S3 兼容对象存储（#89）**：设置 · 数据存储可切换 WebDAV / S3 兼容存储（阿里云 OSS、腾讯云 COS、Cloudflare R2、MinIO、群晖等），SigV4 手写签名零 npm 依赖；技能 / 用量 / 号池 / 记忆四个同步引擎与「配置齐全」判断零改动无缝切换；号池压缩包加密口令支持独立设置（缺省沿用密码 / SecretKey，与历史行为兼容）
- **四大板块启用开关（#91 轻量模式）**：设置 · 通用 · 模块顺序的每一项可启停——停用后左上角置灰不可点，该板块后台的定时器 / 目录监听 / 网关服务 / 数据库全部停止、托盘入口同步隐藏；记忆中枢停用可释放约 80~130MB（全应用内存大头），用量停用不再打开本地库；「至少保留一个板块」防呆，停用反代 / 记忆前弹提示说明影响（网关客户端断开 / 已注入 Agent 的记忆 MCP 不可用）

## 修复

- **WebDAV 服务器配置丢失（#95）**：设置页任何整份保存（切主题、拖模块排序、改反代设置）不再用旧快照冲掉统一服务器配置；系统密钥解密失败（换机 / DPAPI 变化）不再把密文覆盖成空（地址账号还在密码没了的根因）；迁移自愈不再让旧服务器凭据「复活」；设置页新增「清除配置」显式入口（唯一能清掉已存密码的通道）
- **用量归并「确认归并没有任何反应」（#96）**：归并记录放开供应商精确价限制——目标只有其它供应商精确价时按估算计费，不再永远滞留未配置列表（保持「精确 > 通配 > 错配兜底」层级，无别名记录的既有计费口径不变）；归并成功 / 无价可套 / 失败都有明确提示（全局 toast + 弹窗内红字，此前失败提示被弹窗遮罩挡住）；归并目标下拉附价格来源与「仅供应商精确价」徽标；旧版本设备上传价格表不再抹掉本机归并映射；顺带修复旧版 DosageSync 目录迁移后首次打开即崩（no such column: credits）的问题
- **/v1/models 与错误码（#90）**：渠道被「上游启闭」关闭、或一个账号都没有（没有号池）时不再返回该渠道模型；有账号但暂时耗尽 / 冷却仍列出（避免客户端模型列表整体闪没），请求时拿到 503/402 明确文案；访问「目录里查得到但当前不可用」的模型返回 400 channel_disabled（报渠道名与指引，与「模型不存在」的 model_not_found 区分）；fixed 策略下指定渠道被关闭不再「透传试错」；静默回退模型时附 x-agenthub-fallback 响应头（流式为 SSE 注释帧）
- 「保存并重启服务后上游启闭被重置」的修复（2a8b6a5，v1.60.0 之后合入 main）随本版正式发出

# v1.61.0 更新说明

## 新功能

- 新增 **AutoClaw** 双渠道反代接入：`AutoClaw 国内版`（智谱 AutoGLM 加速站）与 `AutoClaw 国际版`（国际站），两地同套协议与签名指纹、账号体系互相独立，各自独立启停 / 路由 / 号池
- **对话转发**：标准 OpenAI 兼容流式，支持工具调用与图片输入；模型路由自动区分计费通道（Coding Plan / 会员按量 / 服务端自动选型），响应回写客户端请求的模型名；远程模型目录一键拉取（未拉取时按两地实测的静态兜底清单 GLM-5.3 / GLM-5.3-Flash 开箱）
- **上游闸门自动处理**：system 提示词白名单规范化（自动前置官方客户端身份段、外来身份句整名改写、幂等不重复）；`max_tokens` 小值自动归一到 10000（上游对小正整数一律拒收且无错误体，撞上时错误提示里附实测排查方向）
- **国内版登录**：添加账号新增「手机验证码」页签——输手机号 → 官方短信通道发码 → 验证入池，全程走官方接口
- **国际版登录**：OAuth 网页登录——点「打开登录页」先弹出官方风控滑块（阿里云验证，前端原样移植官方客户端的求解流程），验证通过自动打开 Z.ai 登录页，回调落在官方登记的四个本机回环端口之一自动入池；支持 Z.ai 账号（Google 通道协议已就绪）
- **从本机客户端导入**：自动识别 `%APPDATA%/AutoClaw/auth.json` 登录态（safeStorage 加密自动解密）与 `~/.openclaw-autoclaw/openclaw.json` 网关配置；国内/国际两区共用同一登录态文件且无地区标记，故两区各给出导入入口、由您选择归属（选错会 401，换一项重导即可）
- **每日签到**：两区每日 `daily_signin` 领积分，判据看积分到账而非 HTTP 状态（已领过如实标「今天已签到」），失败自动拉任务列表归因；支持按渠道的自动签到
- **余额**：积分钱包 + 订阅信息聚合展示（钱包明细按优先级排序，即将过期积分提示）

## 说明

- **token 刷新只读不回写**：AutoClaw 服务端轮换 refresh_token，网关刷新结果只进进程内凭证缓存、不落库——避免与桌面端自己的刷新互相顶掉导致掉登录；代价是网关重启后可能需要重新导入一次登录态
- 客户端版本号、签名密钥、全部端点路径在「规则文件 → headers.json」的 autoclaw / autoclaw_intl 段，客户端升级后改配置即热生效，无需等待发版
- LLM 对话域与账号域的版本号不同（1.17.8 / 1.18.5），后者是模型目录的版本门控，两者都已在配置里
- 新增 `tools/proxy-autoclaw-selftest.cjs` 自测：签名向量、两域请求头互斥（LLM 域禁发 X-Harness-Type / userapi 域必发）、system 规范化幂等、max_tokens 归一、模型路由、假上游端到端（对话 / 目录 / 余额 / 签到幂等 / 刷新不落库 / 凭证缓存）与登录链路
- AutoClaw 双区尚未与真实上游联调（本机无登录态），协议与判据均按官方客户端逆向实证移植；首次真实使用若遇异常欢迎反馈
